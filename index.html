This version of the webrtc-internals dump importer is no longer maintained

For something really powerful, you can use rtcstats.com - it is free as well - and a lot nicer (as you can see on the right).

If you're adamant that you want to use this rusty thing, you can use the version found here.

This is an import tool for dumps from chrome://webrtc-internals. See this blog post for a lengthy description of what it does and how to interpret some of the data.


Legacy getStats detected, these have been removed from Chrome 122 in early 2024. If you need to import such a dump please use an old version of the git repository prior to this commit.
